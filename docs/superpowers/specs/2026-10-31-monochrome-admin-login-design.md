# 黑白拟态登录与后台联动

## 已批准的方向

用户于 2026-10-31 确认黑白拟态登录原型，并要求开始实现。参考原型：`.superpowers/brainstorm/6096-1793418786/content/monochrome-login.html`。图标使用组件库组件，不手写 SVG、不使用 Unicode 字符代替功能图标；允许图标组件内部渲染 SVG。

目标是修改共用后台模板及生成器，使后续生成项目具备登录到后台再退出的完整演示流程，而非只修改 `.vudt/tasks` 中的某次产物。

## 视觉与交互

- 登录页固定黑白银灰主色，不继承后台深色青蓝主色；后台主题和侧栏保持不变。
- 桌面双栏：左侧柔和渐变与立体插画，右侧登录表单。手机变为紧凑插画区加单列表单，无横向溢出。
- 保留原型的内凹输入、立体黑色按钮、柔和高光阴影。动效响应聚焦、悬停、按压和状态变化；遵守 reduced-motion。
- 密码可显隐，表单可键盘操作，有明确错误和提交状态。
- 优先复用生成的 illustration 插槽图片；无图或加载失败使用本地 CSS 立体插画回退，不发起外部图片请求。不改变侧车几何来源。不调用付费模型。
- 原型中的字符图标替换为 `@ant-design/icons-vue` 组件。插画与图标是不同职责。

## 登录闭环

以下为实现建议，作为本次计划默认值：

- 仅演示认证，界面明确提示不输入真实凭证，不上传、不保存密码。公开账号 `demo`，密码 `demo123`；提供填充演示账号操作。
- 演示会话保存在当前标签页 sessionStorage，刷新保留，退出清除。存储不可用时降级内存，不能使页面崩溃。每个导出项目按部署路径隔离会话。
- 存在 auth 页时，未登录访问受保护后台跳到实际 auth 路由；登录后返回合法的项目内目标，无合法目标时进入首个后台页。不硬编码 `/login` 或 `/`。
- 拒绝外部、协议相对、未知路由及 auth 自身作为返回目标，避免开放跳转和循环。
- 已登录访问 auth 页进入后台。顶栏显示演示用户和退出组件按钮，退出后回到登录页，浏览器返回也不能绕过守卫。
- 无 auth 页的项目维持现有直接访问行为，不渲染演示用户/退出控件。
- 多 auth 页选择 spec 页面顺序中的第一个为入口，其余保持公开，不允许作为登录后的返回目标；若无后台页，保持登录页并说明没有可进入的后台，不循环跳转。
- 不实现真实 token、后端认证、RBAC、用户数据库或第三方登录；前端演示守卫不是安全边界。

## 验收

共用模板组件测试、生成器测试、独立导出 vue-tsc/Vite 构建均通过；真实浏览器验证登录、退出、刷新、直接访问受保护路径及安全返回。验证自定义登录路由、无登录页、无后台页、图片缺失、存储不可用和窄屏。视觉截图若工具仍不可见，应明确由用户确认，不把 DOM 检查称为视觉通过。

## 不在本次范围

不修改后台侧栏布局，不补菜单树、部门树、角色权限关系，不修种子数据质量，不自动修改已生成产物，不推送或合并分支。
